# ⛽ Moscow Fuel Availability GIS Analysis (June 18, 2026)

Интерактивный GIS-анализ 23 000+ отзывов с Яндекс Карт по топливному кризису 18 июня 2026 года в Москве и МО.

## 🛠️ Стек технологий
* **Python** (Pandas, Scikit-learn / NLP)
* **H3-py** (Spatial indexing by Uber)
* **MapLibre GL JS** (3D WebGL visualization)

## 📊 Основные результаты
* Собрано и обработано > 23 000 отзывов с пространственно-временной привязкой.
* Классификация отзывов по 7 категориям с учетом контекстных отрицаний (F1-score: **0.91**).
* Динамическая 3D-агрегация на базе H3 гексагонов.

## 🚀 Запуск дашборда локально
Откройте файл `index.html` в любом современном браузере.
